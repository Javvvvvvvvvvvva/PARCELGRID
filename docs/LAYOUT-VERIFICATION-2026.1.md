# 실내 구획·차량 동선 예비 검증

## 범위

- 기존 디자인을 유지하고 계획 스튜디오에 검증 패널을 추가한다.
- 실내 검사는 실제 Stage 2 층 외곽의 동일 로컬 미터 좌표를 사용한다.
- 주거 세대·코어·복도 직사각형 구획 후보를 만들고 수치 편집, 문 재연결, 저장·복원을 지원한다.
- 공간의 경계 포함·상호 겹침·벽 두께 차감 유효폭·문 공유벽·문 유효폭·세대별 계획 전용면적 부족을 검사한다.
- 공용부 연결 탐색은 다른 세대를 통과하지 않는다. 점 접촉은 문 연결이 아니다.
- 외곽·세대수·대상 면적 변경은 저장 구획을 무효화한다. 계획 복제 시 이전 구획의 층·구역 참조는 제거한다.
- 주거·공용부 이외 혼합 층 및 직사각형 템플릿에 맞지 않는 층은 수동 상세 설계 대상이다. 후보 미발견은 건축 불가능 판정이 아니다.

## 차량 검증

- 기존 주차면·통로·코어·기둥 참고점과 같은 좌표를 사용한다.
- 차폭, 길이, 축간 거리, 후방 오버행, 후륜축 회전반경, 여유폭, 가정 기둥 폭을 보존한다.
- 지상 또는 필로티 단일 배치에서 주차면별 내부 진입 후보를 만든다. 혼합·지하·기계식은 미검증이다.
- 직선과 접선 원호로 후륜축 경로를 구성한다. 회전반경을 만족하는 접선 구간이 부족하면 후보 미확보로 표시한다.
- 최대 0.35m 간격의 차량 차체 다각형 사이 볼록 껍질에 회전 구간의 보수적 sagitta 여유를 더해 샘플 사이 간섭도 검사한다.
- 대지 밖 침범, 건물·코어·가정 기둥·다른 주차면 간섭, 최종 정차 시 차량과 여유폭의 주차면 수용 여부를 확인한다.
- 내부 차로의 진입점은 사용자가 조절하는 가정값이다. 전면 직접진입형은 각 주차면에 대응하는 접면 투영점을 가정한다.
- 최대 20면까지 검사하고 나머지는 미검사로 표시한다. 전진 진입과 동일 경로의 후진 복귀만 대상으로 한다.
- 외부 도로에서의 회전, 전진 출차, 다단 후진, 경사·높이, 조향 속도, 보행자와 차량의 동적 충돌은 검사 범위 밖이다.

## 상태 및 승인 경계

- 실내 결과는 `preliminary-fit`, `conflict`, `missing`을 구분한다.
- 차량 후보는 `clear-candidate`, `conflict`, `no-template-fit`, `unavailable`을 구분한다.
- 외부 도로·출입구·구조·피난 검증을 완료하지 않았으므로 `approvalStatus`는 항상 `unverified`이다.
- 실내 예비 통과는 대표안 검증에서 `review`다. 층별 구획과 차량 동선 검증이 미완료이면 대표안 확정을 차단한다.
- 주차 형상 내보내기는 참고 도면으로 계속 가능하지만 차량 동선은 미승인 `review` 상태를 보존한다.
- 구획 및 차량 제원 변경은 매출·전용면적·법정 주차대수·제공 주차대수를 자동 변경하지 않는다.
- 공식 경계가 없으면 임의의 가상 경계를 만들지 않는다. 쌍문동 281-23의 미확정 자료 상태도 그대로 유지한다.

## 가정과 후속 설계

기본 벽 두께 0.2m, 복도 최소 유효폭 1.2m, 코어 3×3m, 문 0.9m, 세대 최소 유효폭 2.4m는 검증용 설계 가정이며 법정 최소값이 아니다. 차폭 1.85m, 길이 4.6m, 축간 거리 2.7m, 후방 오버행 1m, 후륜축 회전반경 5m, 차체 여유 0.1m, 기둥 폭 0.4m도 실측 제원이 아니다.

방·주방·욕실 구획, 창호·채광·피난, 문 여닫힘, 실제 계단·승강기 치수, 층간 코어 정합, 구조 기둥 및 보행 통로는 아직 상세 설계 검증 대상이다. 이번 단계는 완성된 건축 도면 자동 생성이나 인허가 적합 판정이 아니다.
