# PARCELGRID 역할별 검토 워크플로 2026.2

> 이 문서는 브라우저 저장 기반 2026.2 계약의 이력입니다. 현재 서버 권한·감사
> 계약은 `ROLE-REVIEW-WORKFLOW-2026.3.md`를 기준으로 합니다.

기준일: 2026-09-09

## 역할 경계

- 일반 사용자·프로젝트 담당자: 대표안을 저장하고 분야별 검토를 요청한다.
- 건축사: 매스, 법규, 도로, 일조, 주차와 도면 인계 범위를 검토한다.
- 시행·원가 담당: 토지, 공사비, 일정과 실행 조건을 검토한다.
- 금융·회계·세무 담당: PF, 현금흐름, 세후 원장과 세무 계약을 검토한다.
- 보험 인수심사·위험관리 담당: 보험 목적가액, 공사·배상 담보, 면책,
  자기부담금과 선행조건을 검토한다.
- 분양·마케팅·공인중개 담당: 상품, 실거래 근거와 출구가격을 검토한다.

일반 사용자의 검토 요청은 전문가 승인으로 취급하지 않는다. 각 분야는 허용된
전문 역할만 승인할 수 있다.

## 상태 전이

```text
미요청 -> 검토 요청 -> 검토 중 -> 승인
                         |-> 수정 요청 -> 검토 요청
승인 -> 새 검토 요청
```

직접 `미요청 -> 승인` 또는 `수정 요청 -> 승인` 전이는 거부한다. 현재 Snapshot
Key에 연결된 이벤트 이력이 없거나 마지막 이벤트와 현재 상태가 다르면 유효한
승인이 아니다.

## 승인 필수값

승인에는 다음 정보가 모두 필요하다.

1. 요청자와 요청일
2. 검토자, 소속과 분야에 허용된 전문 역할
3. 현재 Stage 3 Review Snapshot Key
4. 근거 문서 참조와 검토일
5. 승인 범위·잔여 조건을 적은 검토 의견
6. 현재 계산·Geometry Snapshot 확인
7. 분야별 원문·근거 확인
8. 인허가·대출·보험·세무 확약이 아닌 예비 타당성이라는 한계 확인

## 보험 검토 Lane

보험 Lane은 다음 세 묶음을 제공한다.

- 대표 Geometry와 공사비 원장에 근거한 보험 목적가액 기준
- CAR/EAR, 제3자 배상, 인접재산·진동·붕괴 위험과 공사기간
- 면책, 보상한도, 자기부담금, 방재·현장조사 선행조건

현재 버전은 보험료나 PML을 자동 산출하지 않는다. 보험사의 인수심사 문서와
실제 목적가액·담보 조건을 승인 근거로 연결한다.

## 변경과 재승인

대표 계획 버전, Geometry Hash, Stage 3 계산, 금융 원문, 가격 검증 또는 세무
계약이 바뀌면 Review Snapshot Key가 바뀐다. 이전 Snapshot Key의 승인은
자동으로 재검토 대상이 된다.

인계 패키지는 승인 이력까지 전달하지만 원문 파일 바이트는 전달하지 않는다.
가져오기 검증기는 현재 저장본과 다른 모든 검토 기록, 허용되지 않은 역할,
누락된 확인란과 상태 전이 이력이 없는 기록을 거부한다.

대표안은 확정 당시 대지 경계·도로·후퇴·용도지역·법규 수치와 그 원문 상태를
`PG-BASIS-*` 해시로 함께 잠근다. 이 기준이 달라지거나 구형 저장본에 해시가
없으면 대표안과 Geometry Snapshot을 자동 해제하고 재확정을 요구한다.

## 남은 경계

현재 저장소는 로컬 브라우저 상태다. 실제 운영 배포에서는 인증된 사용자 ID,
조직 멤버십, 서버 시각, 전자서명, 불변 이벤트 저장과 역할 기반 접근제어를
서버에서 강제해야 한다. 이 작업 전의 승인은 협업 기록이지 법적 전자서명이 아니다.
