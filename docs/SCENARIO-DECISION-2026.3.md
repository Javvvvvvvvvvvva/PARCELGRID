# Scenario Decision Contract 2026.3

## 목적

시나리오를 하나의 숨은 가중 점수로 압축하지 않는다. PARCELGRID는 실행 가능한 후보의 파레토 경계와 목적별 선두를 함께 보존하며, 사용자가 확정한 대표안은 알고리즘 결과와 별도로 유지한다.

모델 버전은 `scenario-decision-pareto-2026.3`이다. 2026.2부터 자동 생성 후보의 용도지역 검토 항목을 후보별 advisory로 보존하며, 2026.3부터 임대형의 실제 원리금 기준 장기대출 DSCR을 공통 순위 제외 지표로 명시한다.

## 최소 비교 조건

다음 중 하나라도 해당하면 투자 후보 파레토 경계에서 제외한다.

1. 유효 사업면적이 없어 물리적으로 실행할 수 없다.
2. 현재 가정에서 세전 손실이다.
3. 확인 자기자본 한도보다 필요 자기자본이 커서 조달 부족이 확정됐다.
4. 용적률·건폐율·층수·정북일조의 확인된 차단 조건이 있다.
5. IRR을 제외한 필수 비교 지표가 유한한 숫자가 아니다.

모든 후보가 최소 조건을 통과하지 못하면 파레토 후보를 만들지 않는다. 이때 화면 비교를 유지하기 위한 기준은 세전 손실이 가장 작은 후보이며, 이는 추천이나 사업 진행 승인이 아니다.

## 독립 목적함수

| 목적 | 방향 | 현재 계산값 |
|---|---:|---|
| 세전 손익 | 최대 | 기준 원장 총매출 - 총사업비 |
| 고원가 스트레스 손익 | 최대 | 직접 공사비 +20% 근사 손익 |
| NPV | 최대 | 요구 IRR로 할인한 자기자본 월별 현금흐름 |
| 세전 IRR | 최대 | 유일한 수치해가 있을 때만 비교 |
| 필요 자기자본 | 최소 | 월별 원장의 누적 실제 출자 요구액 |
| 최대 자금노출 | 최소 | 프로젝트 누적 현금흐름의 최대 절댓값 |
| 사업기간 | 최소 | 취득월부터 최종 회수월까지 |
| 법규 위험 점수 | 최대 | 법규 점검의 공개 감점 결과 |

후보 A가 모든 비교 가능한 목적에서 후보 B와 같거나 앞서고 하나 이상에서 엄격히 앞설 때만 A가 B를 지배한다. 지배되지 않은 실행 가능 후보 전체가 파레토 경계다.

## 법규 검토 상태

- 확인된 법규 차단은 `exclusionReasons`에 들어가 후보 자격을 제거한다.
- 용도지역 사전 스크리닝의 조례·지구단위계획 확인 항목은 `advisoryReasons`에 들어간다.
- advisory는 후보를 비교에서 숨기지 않지만 화면과 보고서에 `확인 필요`로 표시한다.
- 용도 스크리닝은 허가 가능 판정이 아니며 세부 계약은 `ZONING-USE-SCREENING-2026.2.md`를 따른다.

## 비교 기준

- 사용자가 대표안을 확정하면 해당 안을 현재 비교 기준으로 유지한다. 파레토 제외 사유가 있어도 시스템이 다른 안으로 바꾸지 않는다.
- 명시적 대표안이 없으면 파레토 후보 중 `세전 손익 최대`를 초기 비교 기준으로 선택한다.
- 손익 동률은 고원가 손익, NPV, IRR, 필요 자기자본, 최대 노출, 기간, 법규 점수 순으로 초기 화면 기준만 결정한다. 이 순서는 종합점수나 전체 순위가 아니다.

## 공통 순위에서 제외한 값

`장기대출 DSCR`은 안정화 임대 NOI와 LTV·금리·상환기간·계약 만기·최소 DSCR 조건이 있는 후보에만 적용한다. 최대 연 정기 원리금을 사용하고 balloon은 별도 위험으로 표시한다. 매각형에는 적용되지 않으므로 매각형·임대형 공통 파레토 축과 초기 비교 기준에서 제외한다. `hold-period-ledger-2026.3` 별도 임대 보유 렌즈는 혼합안의 개발 매각대금을 유지한 채 남은 임대자산의 갱신·교체, 연차별 DSCR, 재융자 부족액, DSRA, balloon, 운영 현금흐름과 최종 매각을 보여주지만 공통 순위는 바꾸지 않는다.

전문가 확인 세후 손익·NPV·IRR은 세전 공통 순위를 바꾸지 않고
`after-tax-decision-pareto-2026.1` 별도 렌즈에서 비교한다. 확정 입력과 완결 초안은
서로 다른 Pareto 집합이며 계산 기준이 달라진 세무 계약은 두 집합 모두에서 제외한다.

## 남은 한계

1. 장기보유 세후 지표는 상품별 적용성이 달라 공통 세후 Pareto에 포함하지 않는다.
2. 공사비 +20% 손익은 금융비 재계산을 포함하지 않는 근사값이다.
3. 근거 신뢰도는 아직 독립 목적함수로 승격되지 않았다.
4. 후보 공간은 현재 지원되는 용도·규모·매각·임대 조합으로 한정되며 전수 탐색이 아니다.
5. 파레토 후보는 비교할 가치가 있다는 뜻이며 투자 적합성, 인허가 가능성 또는 보험 인수 승인을 뜻하지 않는다.
