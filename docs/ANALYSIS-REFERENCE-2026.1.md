# 예비 분석 기준안 계약

사용자 확인: 2026-10-29 "예비 분석과 공식 승인을 분리해 진행".

## 의미

예비 분석 기준안은 공식 경계·법정 피난 적합·허가·전문가 승인과 별개인 계산 목적의 선택이다. 기존 엄격 대표안 검사에서 review/unknown을 pass로 승격하지 않는다. 저장본 봉인도 승인이나 수익 보장이 아니다.

## 채택 조건

- 현재 입력으로 계산한 건폐율·용적률·높이의 유한한 양수 검토 상한을 충족한다. 상한의 공식 여부는 별도 상태로 남는다.
- 현재 대지 전체 원형·도로와 일치하는 기하 형상이 적격이며 기존 fail 항목이 없어야 한다.
- 유효한 수익 면적, 유효한 세대별 주차 요구, 입력 공급 충족 및 실제 배치 수용량을 확인한다.
- 관측 접면과 전체 주차 후보의 차량 궤적 검사 완료가 필요하다. 미검사·탐색 실패를 적합으로 취급하지 않는다.
- 모든 주거층 실내, 세대별 방·주방·욕실·현관 및 층간 코어·지상 출구 연결을 실제 형상에서 검사한다. 주차면·통로·가정 기둥과 지상 피난 간섭도 포함한다.
- 오래된 면적/사업성 채택 연결은 차단한다. 상세 견적·원가의 기존 fail을 무시하지 않는다.

통과하더라도 주차 후보 수를 공급 대수로 대체하지 않고, 구획에서 계산된 면적을 사업성 면적으로 자동 전환하지 않는다. 사용자가 명시적으로 예비 기준안을 선택할 때 저장된 기존 프로그램으로 사업성을 다시 계산한다.

## 저장과 변경

형상에 선택 버전, 목적 preliminary-analysis, 승인 상태 unverified, 선택 시각, 원본 SHA-256 연결값, 당시 미확정 항목을 저장한다. 키는 대지 근거 전체·층/구획/문·배치·주차·피난·수량 원가·형상 출처/해시에 결속되며 전자서명이나 자격 증명이 아니다.

원본 입력 변경은 예비 선택을 무효화한다. Workspace 및 Stage3는 형식과 현재 입력 연결을 검사한다. 서버 통합 검토는 저장된 통과 플래그에 의존하지 않고 기존 원본 수량·형상·실내·차량·피난·재무 검사를 그대로 수행한다. 통합 버전은2026.10이며 구형 검토는 재봉인·재검토 대상이다. 향후 검사 의미가 달라지면 계약 버전을 변경해야 한다.

계산 입력 근거, 금융기관 약정, 독립 건축/견적/세무/보험/분양 검토 및 관할 승인 경로는 이 계약에서 충족한 것으로 처리하지 않는다.
