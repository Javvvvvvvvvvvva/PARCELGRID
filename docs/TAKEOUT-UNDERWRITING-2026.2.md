# Take-out Underwriting Contract 2026.2

## 목적과 버전

`takeout-underwriting-2026.2`는 임대 안정화 시점의 장기대출 한도, 실제 확약액,
PF 상환 가능액과 계약기간 상환 위험을 분리한다. `2026.1`의 원리금 균등상환
모델을 납부유예, 이자만 납부, 계약 만기, 변동금리 예상 경로, balloon과
DSRA까지 확장한다.

이 결과는 예비 심사 모델이며 금융기관 승인이나 확약을 대신하지 않는다.

## 입력 계약

| 입력 | 단위 | 의미 |
|---|---:|---|
| 안정화 자산가치 | 만원 | LTV 한도의 담보가치 |
| 안정화 연 NOI | 만원/년 | DSCR 상환재원 |
| 보유 전환시 잔존 PF 원금 | 만원 | 전부 임대형은 안정화 시점, 혼합형은 매각대금·유보현금 적용 뒤 재융자 상환 필요액 |
| 최대 LTV | % | 담보가치 기준 상한 |
| 최초 적용금리 | %/년 | 고정금리 또는 예상 변동금리 경로의 최초 all-in 금리 |
| 원리금 상환기간 | 년 | 원리금 상환표의 amortization 기간 |
| 계약 만기 | 년 | 대출 계약 종료 시점 |
| 원리금 납부유예 | 개월 | 현금 납부 없이 이자를 원금에 가산하는 최초 기간 |
| 이자만 납부 | 개월 | 납부유예 뒤 이자만 현금 납부하는 기간 |
| 금리 재설정 주기 | 개월 | 0이면 고정, 양수이면 예상 변동금리 경로 |
| 연 금리 변화 | %p/년 | 리셋 때 적용할 선형 스트레스 가정 |
| 금리 floor / cap | % | 예상 경로의 하한과 상한, 0은 별도 조항 없음 |
| DSRA 적립기간 | 개월 | 최대 연 정기상환액의 월평균 기준 제한현금 |
| 최소 DSCR | 배 | NOI 기준 대출 한도 |
| 확인 대출 확약액 | 만원 | 계산 한도와 별도의 실행 상한 |
| 취급·약정 수수료 | % | 실행 시 종결 현금흐름 차감 |

LTV, 최초 금리, 상환기간, 계약 만기, 최소 DSCR이 없으면
`terms-missing`으로 중단한다. 기간 조합, floor/cap, 범위가 모순되면
`terms-invalid`로 중단한다. 확약액 0은 계산을 허용하되
`modeled-unverified`로 남긴다.

## 월별 금리 경로

재설정 주기를 `R`, 월을 `m`, 연 금리 변화 가정을 `d`라 한다.

```text
경과 리셋 개월 = floor((m - 1) / R) x R
예상 연 금리 = 최초 금리 + d x 경과 리셋 개월 / 12
적용 연 금리 = clamp(예상 연 금리, floor, cap)
```

`R = 0`이면 최초 금리를 전 기간에 적용한다. 변동금리는 실제 기준금리나
시장 forward curve가 아니라 승인된 스트레스 가정으로 만든 예상 경로다.

## 월별 상환 순서

1. 납부유예: `발생이자 = 기초잔액 x 연 금리 / 12`, 현금 납부는 0이고
   발생이자를 원금에 가산한다.
2. 이자만 납부: 발생이자를 현금 납부하고 원금은 줄이지 않는다.
3. 원리금 상환: 당시 금리와 남은 amortization 기간으로 월 상환액을 다시
   계산하고 이자와 예정원금을 분리한다.
4. 계약 만기: 해당 월 정기상환 뒤 남은 잔액을 balloon으로 전액 상환한다.

납부유예와 이자만 납부 기간은 이 순서로 연속 적용한다. 두 기간의 합은
계약 만기를 넘을 수 없다. 계약 만기가 상환기간보다 짧거나 납부유예로
원금이 증가하면 balloon이 발생할 수 있다.

## DSCR과 대출 한도

월별 `정기 원리금`에는 이자 납부와 예정원금만 포함하고 balloon은 포함하지
않는다. 계약기간을 12개월 단위로 묶은 뒤 가장 큰 연간 정기상환액을 심사에
사용한다.

```text
최대 연 정기상환액 = max(각 연차의 정기 원리금 합계)
LTV 한도 = 안정화 자산가치 x 최대 LTV
DSCR 한도 = 안정화 NOI / 최소 DSCR / 원금 1만원당 최대 연 정기상환액
계산 가능액 = min(LTV 한도, DSCR 한도)
모델 대출액 = 확약액이 있으면 min(계산 가능액, 확약액), 없으면 계산 가능액
실제 DSCR = 안정화 NOI / 모델 대출액의 최대 연 정기상환액
Debt yield = 안정화 NOI / 모델 대출액
```

Balloon은 정기 DSCR에 포함하지 않고 금액과 발생 시점을 별도 위험으로
표시한다. 사용자는 DSCR 충족을 만기 상환 가능으로 해석하면 안 된다.

## 수수료, DSRA와 PF 재융자

```text
수수료 = 모델 대출액 x 수수료율
최초 DSRA = 최대 연 정기상환액 / 12 x DSRA 개월 수
종결 순현금흐름 = 모델 대출액 - 수수료 - 최초 DSRA
PF 상환 가능 순유입 = max(종결 순현금흐름, 0)
재융자 부족액 = max(PF 원금 - 종결 순현금흐름, 0)
재융자 여유액 = max(종결 순현금흐름 - PF 원금, 0)
```

종결 순현금흐름은 음수가 될 수 있다. 수수료와 DSRA가 대출액을 넘으면
초과분도 숨기지 않고 추가 자기자본 필요액으로 재융자 부족에 포함한다.
DSRA는 PF 상환이나 투자자 배당에 쓸 수 없는 제한현금이다.

## 상태 계약

| 상태 | 의미 |
|---|---|
| `not-applicable` | 안정화 임대가치 또는 NOI가 없어 비적용 |
| `terms-missing` | 필수 대출조건 누락 |
| `terms-invalid` | 기간·금리·범위 조합 오류 |
| `modeled-unverified` | 계산 가능하지만 대출 확약액 미확인 |
| `commitment-feasible` | 확인 확약액 적용 후 PF 상환 가능 |
| `commitment-shortfall` | 확인 확약액 적용 후 PF 상환 부족 |

## 근거 게이트

임대안은 고정금리 여부와 관계없이 LTV, 최초 금리, 상환기간, 계약 만기,
납부유예, 이자만 납부, 금리 재설정 주기, DSRA, 최소 DSCR, 확약액과 수수료의
원문 근거를 요구한다. 재설정 주기가 양수이면 연 금리 변화 가정과 floor,
cap 근거도 추가로 요구한다. 0개월과 0%가 유효한 조항도 확인된 부재라는
근거가 있어야 한다.

## 미산정 경계

- 실제 기준금리·가산금리 지수와 시장 forward curve
- covenant 재측정, cash sweep, cure, default와 연체이자
- 만기연장 또는 후속 재융자 실행
- DSRA·예치금 운용수익과 세금·보험 escrow
- 대출 법무비, 담보설정비, 조기상환 수수료와 미지급 PF 이자
