# PARCELGRID 유지보수 업데이트 · 2026-08-26

## 이번 업데이트

- 과거 저장 데이터에서 건축 타당성안과 수익 최적안이 같은 물리 계획인데도 두 카드로 보이던 경우를 감지해 `통합 추천안` 한 개로 표시합니다.
- 법적 상한 참고안은 최고 실현 FAR의 2% 범위에서 층판 균형, 지상 주차, 단순한 층수를 우선해 의미 없는 작은 상층이 붙는 형상을 줄였습니다.
- 최고 FAR 후보보다 낮은 균형형 매스를 선택하면 용적률 차이를 경고에 명시합니다.
- 세대면적만 다른 동일 형상의 공간 검증을 재사용하고, 주차대수 반영 전후에 중복 수행되던 공간 검증을 한 번으로 줄였습니다.
- 현재 앱 진입점에서 참조되지 않는 Plan Studio V1~V3, 구형 추천 패널, 중복 대시보드 UI, 폐기된 API 훅과 스키마를 제거했습니다.
- 오래된 `PROJECT_MEMORY.md`를 현재 코드 경로, 불변 계약, 수동 확인 항목 중심으로 다시 작성했습니다.
