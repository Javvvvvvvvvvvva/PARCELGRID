# PARCELGRID 세후 다목적 비교 계약 2026.1

모델 버전은 `after-tax-decision-pareto-2026.1`이다. 세전 Pareto 결과를 대체하지
않고 안정화 매각 전략의 세후 판단 렌즈를 별도로 제공한다.

## 비교 집합

- 확정 집합: 계산 기준이 현재 세전 원장과 일치하는 `expert-confirmed`만 포함한다.
- 예비 집합: 전 세목이 완결됐지만 전문가가 확인하지 않은 `draft`만 포함한다.
- 미산정: `not-configured`, `incomplete`, `invalid`, `stale`은 순위를 만들지 않는다.
- 세전 비교에서 물리·조달·법규·손실로 제외된 안은 세후 이익이 양수여도 복구하지 않는다.

두 집합은 각각 독립적으로 Pareto 경계와 목적별 선두를 계산한다. 초안의 수치가 더
크더라도 확정 후보를 지배하거나 대표안을 바꾸지 않는다.

## 목적함수

| 목적 | 방향 |
|---|---:|
| 세후 손익 | 최대 |
| 세후 NPV | 최대 |
| 세후 IRR | 최대 |
| 필요 자기자본 | 최소 |
| 최대 자금노출 | 최소 |
| 사업기간 | 최소 |
| 법규 위험 점수 | 최대 |

세후 IRR은 유일한 수치해가 계산된 두 후보 사이에서만 비교한다. 장기보유는 모든
상품에 공통 적용되는 전략이 아니므로 공통 세후 Pareto에는 넣지 않고 별도 보유 원장에
유지한다. Pareto 후보는 비교할 가치가 있다는 뜻이며 투자·세무·인허가 승인이 아니다.
