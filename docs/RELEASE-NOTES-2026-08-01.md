- 원문 PDF/Excel/CSV 저장을 외부 배포 서비스에서 로컬 비공개 폴더로 전환하고 경로 탈출 방지·파일 권한·SHA-256 식별을 적용했습니다.
- 주소 조회와 프로젝트 계산 실패 응답에 오류 코드, 재시도 가능 여부, 다음 조치를 추가했습니다.
- 프로젝트 오류 화면에 다시 시도, 주소부터 다시 시작, 환경 점검 동선을 연결했습니다.

- 이미지 기준 계획 DNA에 실제 geometry source, 정확 좌표 보유 여부, 형상 복원 경고, 금지 요소를 포함했습니다.
- 단가가 0원이거나 미입력일 때 재료 공사비가 계산된 것으로 오인되던 문제를 수정했습니다.
- 세무·민감도·가정 탭을 시나리오 상세 화면에 다시 연결했습니다.
- 보고서 Evidence Gate가 실제 견적·Term Sheet·가격 검증·세무 승인 상태를 반영하도록 정합성을 맞췄습니다.

- 오래된 배포 구성, 중복 CI, 미사용 인증·외부 저장 의존성, OS 메타데이터와 잘못 생성된 셸 출력 파일을 제거했습니다.
