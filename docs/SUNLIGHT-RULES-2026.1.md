# PARCELGRID 일조·채광 규칙 계약 2026.1

## 목적

sunlight-rules-2026.1은 Stage 2 계획, 3D 건축가능영역, 추천 후보, Stage 3 법규 요약과 보고서가 같은 일조·채광 판정을 사용하게 하는 버전형 계약이다.

이 엔진은 다음 값을 서로 분리한다.

- 법규 적용 여부: applies, not-applicable, review
- 법정 거리와 공지 기준선 이동 후 대지 내부 유효 거리
- 실제 계획 거리와 준수 여부
- 규칙 출처 상태와 입력 증거 상태

자료가 없다는 이유로 위반을 만들지 않으며, 사용자 입력이나 지도 관측을 원문 확인으로 승격하지 않는다.

## 정북일조

전용주거지역·일반주거지역의 일반 건축물은 다음 기본식을 사용한다.

- 높이 10m 이하: 북측 1.5m
- 높이 10m 초과: 해당 부분 높이의 1/2

서울특별시 조례 제35조에는 2층 이하·8m 이하 건축물을 자동 배제하는 규정이 없다. 따라서 서울의 2층 7.9m 계획도 다른 확인된 예외가 없으면 1.5m를 적용한다.

다음 예외는 원문 확인 또는 전문가 승인 상태일 때만 적용한다.

- 정북방향 인접대지가 전용·일반주거지역이 아닌 경우
- 시행령상 20m 도로와 지정구역 요건 전체를 충족한 경우
- 건축협정 예외가 확인된 경우
- 해당 관할 조례의 저층 예외가 확인된 경우

도로·공원·하천 등 공지가 있을 때 일반 정북일조 기준선은 반대편 경계로 이동한다. 공지 유형과 폭이 결정 등급이 아니면 형상 면적을 늘리지 않는다.

## 공동주택 채광·동간거리

공동주택 여부는 건축법상 세부 용도로 판단한다. 기존 화면의 다가구·다세대 통합 선택은 단독주택 범주의 다가구와 공동주택 범주의 다세대를 구분하지 못하므로 자동 확정하지 않는다.

- 일반 채광방향 경계: 벽면 높이의 1/2
- 근린상업지역·준주거지역: 벽면 높이의 1/4
- 서울 다세대주택: 인접대지경계선 1m
- 공지 기준선: 중심선
- 같은 대지에서 채광창이 마주보는 경우: 원칙적으로 높은 건물 높이의 1/2
- 도시형생활주택 관계: 높이의 1/4, 서울 단지형은 최소 4m
- 고층 채광창과 저층 건물 관계: 10m와 저층 높이 비율값 중 큰 값
- 채광창 벽과 창 없는 벽: 8m
- 측벽과 측벽: 4m

현재 PARCELGRID의 단일 매스 계획은 같은 대지 내 건축물 수를 1동으로 기록한다. 다동 계획 기능이 추가되면 벽면 관계와 실제 동간거리를 좌표에서 산출해야 한다.

## 높이·형상 계약

- 높이는 지상층의 실제 층고를 아래에서 위로 누적한다.
- 옥상 구성·파라펫 여유는 최상층에 한 번만 더한다.
- 각 층의 누적 높이로 계단식 북측 이격을 계산한다.
- 확인된 공지 폭만 법정 거리에서 차감한다.
- 적용 조건이 미확인인 경우 기본 이격을 보수적으로 3D 형상에 적용하되 법규 통과로 표시하지 않는다.

## 현재 한계

- 북측 인접대지 용도지역, 공지 폭, 지표면 고저차를 자동 취득하지 않는다.
- 채광창이 있는 실제 벽면과 동간 최단거리를 3D 좌표에서 자동 검출하지 않는다.
- 서울 외 지자체 조례 이력은 아직 등록되지 않았다.
- 결과는 인허가 확정이 아닌 예비 타당성 검토이며, 결정 등급 판정도 건축사 최종 검토를 대체하지 않는다.
