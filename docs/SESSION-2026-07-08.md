## 1. 디자인 시스템 & Envelope 페이지

### 디자인 방향
- **흑백 + 절제된 적색** (부정/리스크만) 통일
- 공용 프리미티브 사용: `Panel`, `SectionTitle`, `DataRow`, `Button` (`src/components/ui/primitives.tsx`)

### Envelope 페이지 (`/projects/[id]/envelope`)
- **2열 레이아웃**: 왼쪽(결과) / 오른쪽(조작)
  - 왼쪽: 실시간 계획, 토지 분석(법적 최대치), 정북 일조, 3D 매싱
  - 오른쪽: STEP 1~5 (시나리오 → 용적률 → 세대상품 → 세대수 → 층수), 내 계획 요약
- sticky 제거 (스크롤 시 레이아웃 깨짐 방지)
- 3D 매싱: 도로폭 이격 표현 유지 (단순 검정 처리 안 함)

### `unitAreaSqm` 정의 수정 (건축사 피드백)
- **세대당 연면적 배분 기준** (공용부 포함), 전용면적 아님
- 라벨: `35㎡ — 세대당 연면적 기준` + `전용 25~30㎡` 등 `netAreaLabel` 병기
- 단독 2층 / 다가구 3층 = **초기 추천값** (법적 최대 아님) UI 문구 반영

## 3. 건축 타당성 점수 (Buildability Score)

### 별점(★) → 0~100점 감점식
- 투자성(IRR)과 **분리** — 건축성 vs 투자성은 다른 축

### 배점 (합계 100)
| 축 | 배점 | 설명 |
|---|---|---|
| 법규 적합성 | 25 | 인허가 리스크 |
| 정북일조 | 20 | 이격·배치 깊이 |
| 주차 | 15 | 배치 미확정 시 중립 감점 |
| 시공성 | 15 | 층수·구조 난이도 |
| **세대 계획 적정성** | 15 | 실제 세대당 면적 ÷ 상품 기준면적 |
| 확장성 | 10 | 용적률 잔여 (연속 점수) |

### 세대 계획 적정성 (신규)
- 세대수가 많아서 감점 ❌
- **상품 기준면적 대비 세대 협소** 시 감점 ✅
- 예: 투룸형 50㎡ 기준, 세대당 34㎡ → `−5 세대적정`

### UI (`ScenarioComparisonTable`)
- "추천도(별)" → **"건축 타당성"** (점수 /100 + 감점 목록)
- 용적률: **`80% / 상한 200%`** 병기 + 툴팁 (실현 vs 법정 상한)

### 관련 파일
- `src/lib/finance/score-engine.ts`
- `src/lib/finance/scenario-verdict.ts`
- `src/components/ui/ScenarioComparisonTable.tsx`

## 4. 권장안 층수 — 하드코딩 제거

### Before
- `RECOMMENDED_FLOORS` 고정 (다가구 3층, 단독 2층)

### After
1. 후보: **1층 ~ 법규상 최대 층수**
2. 각 후보별 연면적·일조·주차·건축 타당성 점수 계산
3. **최고 점수안** = 권장안

### 동점 처리
1. 건축 타당성 점수
2. 정북일조 충족 (ok > warn > fail)
3. 주차 대수 적음
4. 연면적 높음

### 제품 구조 (확정)
| 화면 | 역할 |
|---|---|
| **Envelope** | 사용자 의도 입력 ("나는 4층 3세대로 짓겠다") |
| **비교/분석** | 엔진 평가 + 권장 ("이 부지는 2층이 더 적합") |

→ Envelope 로직과 권장안 엔진은 **의도적으로 분리** (Envelope STEP1 초기값은 별도 유지)

## 6. 대시보드 레이아웃 정리 (`/projects/[id]`)

### 메인에서 제거
- 실거래 비교 (`CompsTable`) — 전용 페이지로
- PF 현금흐름 미니 차트 — 시나리오 상세에서

### 우측 사이드바로 이동
- **규제 매트릭스** (`RiskMatrix` compact 모드)
- **데이터 출처** / **규제 매트릭스** → 클릭 접기/펼치기 (기본 접힘)

### 핵심 가정 (사이드바)
- **분양가·임대료** 인라인 편집 (what-if)
  - 분양가: `주변 실거래 기반`
  - 임대료: `기본 가정값 · 수정 필요`
- 공실률·Cap Rate·PF 금리 → 읽기 전용 (가정 편집 페이지에서)
- **`✎ 모든 가정 편집`** → `/overrides` 네비게이션 연결

### KPI 즉시 재계산
- 사이드바에서 분양가/임대료 변경 시 `calculateScenario` 클라이언트 재계산
- `가정 편집 반영됨` 배너 + 기본값 복원

### 가정 draft 공유 (`project-store`)
- `draftAssumptions` — 대시보드 ↔ 가정 편집 페이지 공유
- `localStorage` persist (새로고침 유지)

## 7. 권장안 적용 / 되돌리기

### 제품 철학
- AI가 설계를 **강제로 바꾸지 않음**
- 사용자 입력 → AI 평가 → **사용자가 선택**

### UX
- 권장안 카드: **`권장안 적용`** 버튼
- 적용 후: **`내 계획 되돌리기`** (토글)
- `envelopePlan` + `recomputeFromEnvelope`로 분석 즉시 반영
- Envelope 페이지: store 값으로 슬라이더 **최소 동기화** (마운트 시)
