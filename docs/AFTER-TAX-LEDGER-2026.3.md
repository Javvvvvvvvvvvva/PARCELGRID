# PARCELGRID 세후 원장 계약 2026.3

기준일: 2026-09-09  
원장 모델: `after-tax-ledger-2026.2`  
입력 계약: `expert-tax-input-2026.3`

## 핵심 계약

세후 원장은 안정화 매각과 장기보유 전략별로 8개 세목의 납부·환급 일정을
세전 자기자본 월별 현금흐름에 연결한다. 기존 부동산 취득세는 세전 사업비에
이미 포함되므로 전문가 금액과 대사만 하고 다시 차감하지 않는다.

`expert-confirmed`는 다음 조건을 모두 만족할 때만 의사결정 등급이다.

1. 모든 세목이 `confirmed` 또는 근거가 있는 `not-applicable`이다.
2. 납세의무자, 기준일, 문서 번호와 프로젝트 전용 SHA-256 원문이 있다.
3. 로그인한 회계사 또는 세무사의 신원·조직·확인 시각이 계약에 남는다.
4. 작성자 이름과 인증된 확인 주체가 일치한다.
5. `PG-TAX-BASIS-*` 계산 기준이 현재 세전 현금흐름과 정확히 일치한다.

## 계산 기준 잠금

계약은 아래 값을 `after-tax-calculation-basis-2026.1` Snapshot으로 보존한다.

- 전체 세전 자기자본 월별 현금흐름
- 세전 원장에 포함된 기존 부동산 취득세
- NPV에 사용하는 요구수익률

매출, 공사비, 금융조건, 사업기간 또는 요구수익률 변경으로 이 세 값 중 하나라도
달라지면 상태는 `stale`이 된다. Stale 계약의 세후 손익·NPV·IRR은 모두 숨기고,
현재 기준으로 계약을 다시 저장한 뒤 전문가가 재확인해야 한다. 해시는 빠른 식별용이며
판정할 때는 Snapshot 본문도 함께 비교한다.

## 상태 경계

| 상태 | 세후 수치 | 확정 의사결정 사용 |
|---|---|---|
| `not-configured` | 미산정 | 불가 |
| `incomplete` | 부분 초안 | 불가 |
| `invalid` | 미산정 | 불가 |
| `stale` | 미산정 | 불가 |
| `draft` | 완결 초안 | 예비 비교에서만 가능 |
| `expert-confirmed` | 전문가 확인 원장 | 확정 세후 비교 가능 |

이 확인은 세무 신고나 법적 전자서명을 대신하지 않는다. 실제 과세표준, 중과·감면,
부가가치세 과세 여부와 사업주체별 처리는 담당 전문가가 최신 법령과 원문으로 다시
확인한다.
