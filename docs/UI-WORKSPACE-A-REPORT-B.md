# A 작업형 / B 경영진 요약 — UI 적용 1차

기준 커밋: `5b1fee5806ec3fcdb36733c3772dc8f2fddc6f90`.
사용자가 선택한 시각 방향: 기본 프로젝트 화면은 부지 중심 A, 보고서는 문서형 B.

## 적용 범위

- `/projects/[projectId]/overview`: 저장된 부지·대표안 도면, 결정 요약, 저장 사업성, 확인 항목.
- `/projects/[projectId]/report/brief`: 동일한 읽기 전용 결과를 문서형으로 표시하는 경영진 요약.
- 공통 프로젝트 셸: 밝은 배경, 라벨 내비게이션, 실제 데이터 상태, 네 역할 프리셋, 모바일 메뉴.
- 홈의 기존 데모 링크는 새 overview로 진입한다. 신규 부지 입력 흐름과 기존 사업성 루트는 그대로 유지한다.
- 수치마다 원본 필드·단위·근거 상태를 확인하는 키보드 접근 가능한 dialog.
- 기존 상세 보고서 `/report`, 인계·승인, 계획 편집, 내보내기, 사업성 입력 화면은 변경하지 않는다.

이 패치는 1차 통합이다. 계획 스튜디오 내부 재배치, 독립 비교 페이지 재구성, 전체 상세 화면의 스타일 교체는 포함하지 않는다. 기존 `/comparison` 리디렉션 동작도 유지한다. 새 보고서 요약은 공유 권한이나 외부 공개 링크를 만들지 않는다.

## 변경하지 않는 경계

`src/lib/finance`, `src/lib/planning`, `src/lib/regulatory`, `src/lib/stores`, 기존 adapter/schema/API/lockfile은 수정하지 않는다. 프로젝트 layout의 hydration/recompute effect는 원본과 바이트 단위로 유지한다.

`useProjectOverview`는 기존 저장소를 읽고 기존 정합성/검증 함수를 호출할 뿐 계산·저장·대표안 확정을 실행하지 않는다. 역할은 별도 `parcelgrid.ui.workspace-role.v1` localStorage 키에만 저장된다.

금액은 대표안에 일치하는 저장 스냅샷의 ScenarioVM 값을 사용한다. 다른 프로젝트·미검증 형상·이전 버전·변경된 입력에는 금액을 숨기고 기존 화면에서 저장하도록 안내한다. 원문 등록 미완료는 예비 계산값의 존재와 분리한다. 세후 수익은 생성하지 않는다. 현재 등록된 금융 원문은 저장 시점 원문의 불변 복사본이 아니므로 패널에 이 제한을 표시한다.

SVG는 기존 좌표의 화면 투영만 수행한다. 면적·규제·수익 산출, 도로 폭 추정, 주변 필지 생성, 새로운 건물 생성은 하지 않는다. 검증된 형상이 없으면 부지 좌표만 보여준다. Higgsfield 또는 생성형 이미지 API를 호출하지 않는다.

## 검증

- 로컬 TypeScript 구문/JSX 변환 검사와 순수 표시 로직 테스트를 별도로 실행한다.
- 전체 `pnpm verify` 및 실제 Next.js/React 브라우저 회귀는 필수 merge gate이다.
- 이 작업 환경은 Node 22이며 저장소의 Node 24 / pnpm 11 의존성을 설치할 네트워크가 없어 전체 verify를 실행하지 못했다. 병합 전에 해당 검증을 수행해야 한다.

확인할 실제 브라우저 흐름: 새 브라우저 데모 진입 → overview → 부지·규제 → 대표안 확정 → 사업성 저장 → overview/brief 금액 일치 → 입력 변경 시 금액 숨김 → 원문 패널 열기/Escape/초점 복귀 → 모바일 메뉴 → 상세 보고서·인계·DAE/DXF 기존 동작 → 인쇄 미리보기.

## 브랜치 및 병합 기준

UI 변경은 `ui/workspace-a-report-b` 브랜치에서 검토한다. `master` 병합이나 운영 배포는 이 패치에 포함하지 않는다.

게시 전 준비한 14개 파일의 Git blob 해시 일치, 12개 TypeScript/TSX 파일의 구문 변환, CSS 파싱, Node assert 하네스의 순수 표시 로직 15개 검사를 확인했다. 이는 전체 타입 검사·Vitest 실행·Next.js 빌드·브라우저 검증을 대체하지 않는다. PR의 실제 CI 결과와 위 수동 흐름을 확인한 뒤 병합한다.
