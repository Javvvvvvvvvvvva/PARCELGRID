# 전체 층 실내 후보 자동화

`interior-automation-2026.1`, 2026-10-29. 공식 승인과 분리된 예비 후보 생성 기능이다.

## 입력과 범위

- 현재 계획의 전체 층 외곽·높이 기하 검사, 같은 원본의 도로 접면·주차 장애물 자료가 필요하다. 잠긴 형상은 편집할 수 없다.
- 최대32개 층/전체120세대, 층당20세대 이내의 기존 주거·공용부 직사각형 템플릿 범위다. 무주거·중복 층·없는 지상1층·미확인 주차/형상은 차단한다. 지원 한도 내의 모든 부지에 후보를 찾는다는 보장은 없다.
- 기존 공간/문/실/출구는 기본적으로 보존하고 없는 부분만 생성한다. 기존 구획을 바꾸려면 별도 교체 옵션을 켜고 결과를 확인한 뒤 적용해야 한다.
- 신규 상세 실의 침실 수는0~3개. 기존 실 가정은 기본 보존한다. 새 구획의 계단 예약 크기는 입력 층고와 기존 계단 가정에서 계산하며 벽 여유를 포함한다. 법정 최소값으로 확정하지 않는다.

## 생성과 적용

- 기존 구획·실 생성기를 재사용한다. 코어 폭/깊이6개 조합 안에서 최초 전체 연결 후보를 찾는다. 수익/전용률의 전역 최적화나 설계 가능성 증명은 아니다.
- 실 유효폭/면적·문·세대 현관·공용부·층간 코어·지상 출구를 재검사하고 주차면/통로/기둥과 간섭을 검사한다. 고립·중복 상세 실도 차단한다.
- 생성8초 cooperative deadline, Worker12초 hard stop. 내부 피난 계산 한도도 미완료로 전파한다. 미완료/후보 미확보에는 적용 가능한 부분 결과를 반환하지 않는다.
- 생성과 적용 직전 재검사 모두 전용 Worker에서 실행한다. 진행률과 취소를 제공하며 완료/실패/취소 시 Worker를 종료한다.
- 결과는 미리보기일 뿐 자동 저장/채택하지 않는다. 명시적 적용은 원본을 다시 검사하고 층의 `interiorLayout` 및 `egressPlan`만 반영한다. 프로그램 면적/층수/세대수/단가/금융/주차 공급은 그대로 둔다.
- 생성 이후 계획·대지·옵션·대표안·계정/조직·선택 변경 시 결과를 폐기한다. 적용 재검사 중 변경/취소도 쓰기 전에 확인한다. 편집에 따른 기존 대표안/봉인 최신성 무효화는 기존 저장소 계약을 따른다.
- 예비 분석 기준안 채택, 사업성 계산, 공식 자료 확인, 전문가 승인은 각각 별도 단계다. 이 기능은 어떠한 승인도 생성하지 않는다.

## 미검증 범위

한 개 공용 코어의 예약 공간과 가구 없는 중심선 후보다. 실제 계단 단면/머리높이/난간/구조/층간 개구부/방화구획/법정 직통계단 수와 보행거리/창호/채광/설비/문 여닫힘/장애인 접근/도로까지 안전 통로는 미검증이다. 지하층·복잡한 불규칙 평면·다동·여러 코어를 포함한 전체 설계 자동화 완료를 뜻하지 않는다.

실내 피난 화면도 `parkingEgressObstacles`를 공통 사용한다. 통로를 제외한 화면만 예비 통과하고 서버에서는 실패하는 차이를 없앤다. 도로 원본이 결속되지 않은 주차는 알려진 장애물로 가장하지 않는다.
