# Project Ledger 2026.6

## 목적

`project-ledger-2026.6`는 Stage 3의 세전 손익, PF 이자·최고잔액, 필요 자기자본, IRR·NPV와 분기 현금흐름이 공유하는 월별 원장이다. 같은 입력은 같은 원장을 만들며 모든 금액 단위는 만원이다. 2026.5부터 임대 안정화 수입 상계 직전 PF 원금을 장기대출 검토 입력으로 보존하며, 2026.6부터 매각 수입이 없는 전부 임대형에는 사용되지 않는 분양·매각 기간을 적용하지 않는다.

이 모델은 예비 사업성 비교용이다. 금융기관 약정, 신탁계약, 세무조정과 투자확약을 대체하지 않는다.

## 비용 항목

월별 원장은 다음 항목을 분리한다.

1. 부동산 취득대금
2. 취득세 반영액
3. 기타 취득 부대비
4. 철거비
5. 명도·임차인 정리비
6. 직접 공사비
7. 설계·감리·인허가 등 간접비
8. 예비비
9. PF 이자
10. PF 약정·취급 수수료
11. 신탁·자금관리비

취득세·기타 취득 부대비·명도비·PF 수수료·신탁비의 기본값 0은 면제 또는 비용 없음의 확정이 아니다. 근거자료가 없어서 총사업비에서 제외된 상태이며 소스 데이터 게이트를 통과하려면 각 값의 원문 또는 승인 근거가 필요하다.

PF 약정·취급 수수료는 다음 계획 한도에 입력 수수료율을 곱한다.

```text
PF 계획 한도 = (직접 공사비 + 간접비 + 예비비) x LTC 목표
PF 수수료 = PF 계획 한도 x PF 수수료율
```

## 수익 회수 정책

- 오피스텔 등 주거 분양: `10/60/30` 예비 회수 일정
- 단독·다가구 통매각: 종료월 100% 회수
- 상가·업무 매각: 주거 분양대금과 분리해 종료월 회수
- 주거·상가·업무 임대 출구가치: 임대 안정화 기간 이후 종료월 회수

혼합용도 계획은 풀별 정책을 각각 저장한다. 상가·업무 매각대금을 주거 분양 일정에 섞지 않는다.

## 월별 자금 순서

각 월은 다음 순서로 계산한다.

1. 직접·간접 공사비와 예비비의 LTC 비율만큼 PF를 인출한다.
2. 월초 PF 잔액과 당월 인출액 절반을 기준으로 이자를 계산한다.
3. 기존 유보금과 당월 매출로 PF를 우선 상환한다.
4. 남은 현금으로 자기자본 부담 비용을 지급한다.
5. 부족분은 `필요 자기자본`으로 기록한다.
6. 조기 매출 잉여금은 프로젝트 계정에 유보하고 종료월에만 배당한다.
7. 종료월 PF 상환 부족액은 추가 필요 자기자본으로 명시한다.

조기 분양대금을 공사 중 투자자 배당으로 내보내지 않으므로 예비 IRR이 임의로 앞당겨지지 않는다.

## 자금조달 상태

- `unverified`: 확인 자기자본 한도가 0 또는 미입력이다. 필요액은 계산하지만 조달 가능하다고 판정하지 않는다.
- `funded`: 확인 한도가 원장의 누적 필요 자기자본 이상이다.
- `shortfall`: 확인 한도가 부족하다. 부족액과 최초 부족 월을 반환한다.

구조조정 경로와 최대 취득대금 역산은 `shortfall` 결과를 성공안으로 인정하지 않는다. `unverified` 결과는 예비 계산을 계속할 수 있지만 최종 보고서 완료와 전문가 인계는 차단한다.

## 임대 NOI와 부채 지표

수익 계약 `revenue-valuation-2026.2`는 다음 단계를 보존한다.

```text
잠재 연 임대료
- 공실 손실
= 유효총수입(EGI)
- 소유자 부담 운영비
= NOI
```

현재 운영비율 기본값 20%는 내부 초기 가정이며 운영예산 또는 유사 자산 실적으로 교체해야 한다.

`project-ledger-2026.6`는 임대 안정화 월의 상환 전 PF와, 사업 종료까지 확보된 비임대 매각대금·유보현금을 먼저 적용한 보유 전환 잔존 PF를 각각 보존한다. `takeout-underwriting-2026.2`는 후자의 `pfBalanceAtRetainedLeaseRefinance`와 금융기관 조건을 사용해 최대 연 정기 원리금 기준 DSCR, 수수료·DSRA 차감 종결 현금흐름과 재융자 부족액을 계산한다. 필수 조건이 없으면 DSCR은 `N/A`다. 장기대출 이후 운용은 개발 원장을 바꾸지 않고 `hold-period-ledger-2026.3` 별도 대안 원장에 연결한다.

## 대사 규칙

- 총매출 = 여섯 수익 풀 가치 합계
- 총사업비 = 열한 비용 항목 합계
- 세전손익 = 총매출 - 총사업비
- 자기자본 현금흐름 합계 = 총매출 - 총사업비
- PF 종료잔액 = 0이며 부족 상환액은 필요 자기자본에 포함

`누적 자기자본 + PF 최고잔액 = 총사업비`는 시점이 다른 값의 합이므로 회계 항등식이 아니다. 조달과 상환은 월별 원장에서 확인한다.

## 별도 보유 원장과 아직 미산정인 항목

`hold-period-ledger-2026.3`은 전부 임대형과 혼합 매각·임대형에서 임대료 면제, 임차인 갱신·교체, 후속 공실·TI·중개수수료, 제한 보증금, 월별 임대수입·운영비, 교체 준비금, 대수선, 장기대출 정기 원리금·DSRA·balloon과 최종 매각을 별도 현금흐름으로 계산한다. 자세한 계약은 `HOLD-PERIOD-LEDGER-2026.3.md`를 따른다.

- 재산세·부가세·법인 세무조정과 세금 납부 시점
- 개발 종료 전 임대 안정화 구간의 중간 운영수입
- 임차인·호실별 비동기 만기, 중도해지, 연체와 대손
- 보증금 운용수익과 제한계정 이자
- PF 이자 자본화, 약정 위반, 기한이익상실과 실제 담보·보증 구조

이 항목들이 입력·원장·출처 계약으로 연결되기 전에는 결과를 세후 확정 수익이나 대출 승인 가능액으로 표시하지 않는다.

## 회귀 기준

- 상가·업무 매각은 주거 분양의 조기 회수액을 바꾸지 않는다.
- 모든 비용 항목 합계와 총사업비가 일치한다.
- 조기 분양 잉여금은 종료 전 배당되지 않고 유보잔액으로 남는다.
- 자기자본 한도 미확인·충분·부족 상태와 최초 부족 월이 구분된다.
- 안정화 직전 PF 원금이 해당 월의 `pfBalanceBeforeRepayment`와 일치한다.
- 보유 전환 잔존 PF는 종료월 비임대 매각대금과 진입 전 유보현금을 중복 조달하지 않는다.
- 전부 임대형은 분양·매각 기간과 무관하게 임대 안정화 월에 종료하며, 매각 수입이 있는 안만 분양·매각 기간을 사용한다.
- 수익성이 좋아도 자기자본 한도가 부족하면 구조조정·최대 취득대금 성공안이 아니다.
- 분기 현금흐름 합계가 같은 월별 원장의 총유출·총유입과 일치한다.
