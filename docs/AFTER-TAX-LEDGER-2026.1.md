# PARCELGRID 세후 원장 계약 2026.1

> 이 문서는 작성자 메타데이터 기반 2026.1 계약의 이력입니다. 인증된 세무
> 현재 계약은 계산 기준 잠금을 포함하는 `AFTER-TAX-LEDGER-2026.3.md`입니다.

기준일: 2026-09-09  
모델: `after-tax-ledger-2026.1`  
입력 계약: `expert-tax-input-2026.1`

## 목적

PARCELGRID의 기본 사업수지는 세전 원장이다. 세후 지표는 세법 참고세율을
프로젝트 숫자에 자동으로 곱해 만들지 않는다. 세무 전문가가 사업주체와
과세 사실관계를 검토한 뒤 입력한 납부·환급 현금흐름만 별도 세후 원장에
반영한다.

## 전략별 계약

계약 키는 `projectId + scenarioId + strategy`다. `strategy`는 다음 둘 중 하나다.

- `stabilized-sale`: 개발 후 매각 또는 임대 안정화 가치 매각
- `long-term-hold`: 장기대출 실행 후 운영하고 최종 매각

한 전략의 세무 입력을 다른 계획안이나 다른 처분전략에 재사용하지 않는다.

## 필수 세목

1. 기존 부동산 취득세
2. 신축 건물 취득세
3. 재산세·보유세
4. 부가가치세 순정산
5. 법인세·소득세
6. 지방소득세
7. 토지·주택 처분 추가과세
8. 기타 세금·공과

각 세목은 `미검토`, `금액 확정`, `해당 없음` 중 하나다. `해당 없음`도 근거
메모가 필요하다. 확정 세목은 0개 이상의 납부·환급 일정을 가지며 각 일정은
월, 금액(만원), 방향을 기록한다. 확정 0원은 금액 누락이 아니라 전문가가
검토한 0원이어야 한다.

## 중복 차감 방지

`acquisitionTaxManwon`은 토지 인수 월의 세전 사업비와 자기자본 현금흐름에
이미 포함된다. 세무 계약의 기존 부동산 취득세는 이 값과 1만원 이내로
대사해야 하며 세후 원장에서 재차 차감하지 않는다. 불일치하면 계산 상태는
`invalid`가 되고 Stage 3 취득세 원본 입력을 먼저 고쳐야 한다.

나머지 7개 세목만 증분 세후 현금흐름이다.

```text
세후 자기자본 CF(t)
= 세전 자기자본 CF(t)
- 전문가 확정 납부액(t)
+ 전문가 확정 환급액(t)
```

납부일이 기본 사업기간 뒤라면 현금흐름 배열을 해당 월까지 연장한다. 세후
손익, NPV, IRR, Equity Multiple과 회수기간은 이 연장 배열에서 다시 계산한다.

## 상태

- `not-configured`: 계약 없음. 세후 지표를 표시하지 않는다.
- `incomplete`: 미검토 세목 또는 전문가 메타데이터가 남았다. 입력된 확정
  현금흐름은 계산할 수 있지만 투자 확정값이 아니다.
- `invalid`: 계획안·전략 불일치, 금액·월 오류, 취득세 대사 실패 또는 잘못된
  원문 메타데이터. 세후 지표를 계산하지 않는다.
- `draft`: 모든 세목이 검토됐지만 전문가 확인 상태가 아닌 완결 초안.
- `expert-confirmed`: 전 세목과 작성자·원문이 완결된 의사결정 등급 입력.

전문가 확인에는 납세의무자 유형, 작성자, 자격·역할, 기준일, 문서 번호,
프로젝트 전용 저장경로와 유효한 SHA-256을 가진 PDF·Excel·CSV 원문이 필요하다.

## 승인과 인계

세무 계약 내용은 Stage 4 검토 Snapshot Key에 포함된다. 납부액, 환급액,
시점, 판정 또는 원문이 바뀌면 기존 승인은 자동으로 오래된 승인이 된다.
인계 JSON에는 계약과 원문 메타데이터만 포함되며 파일 바이트는 포함되지
않는다. 가져온 계약은 원문을 다시 연결할 때까지 `draft`로 강등된다.
