# 17공종 견적 금액 배분 원장

기준일: 2026-11-10, America/Chicago. 모델 `construction-scope-ledger-2026.1`.
견적 입력의 산술·포함 범위 대사이며 실제 전체 물량 산출이나 전문가 승인이 아니다.

## 입력과 계산

- 기존 `construction-quote-2026.1`의 각 행에 선택적 `allocations`를 추가했다. 항목은 공종 ID, 원 단위 금액(미입력은 null), 300자 이하 원문 배분 근거다. 행별17개, 견적 전체256개 이하이며 중복 공종/음수/문자열 금액/비유한 수치를 거부한다. 기존 미배분 견적은 변환 없이 보존한다.
- 단일 공종 행은 그 행 금액을 사용한다. 여러 공종을 묶은 행은 연결된 모든 공종의 배분 금액과 근거가 있어야 한다. 자동 균등 배분이나 면적 비례 추정은 하지 않는다.
- Decimal로 배분 합계를 계산하며 원문 행 금액과 정확히 일치해야 한다. 금액은 원문 행당 한 번만 합산한다. 수량×단가 및 문서 합계의 기존1원 대사 허용오차와 배분의 정확 일치 조건은 별개다.
- 입력 부분합, 배분 금액, 미배분 입력 금액을 구분한다. 누락 금액은 부분합에 포함하지 않으며 모든 금액이 비어 있으면 부분합도 null이다. 부가세 기준이 다르거나 미확정이면 합산하지 않는다. 일부 유효 행이 있어도 미확정/불일치가 남으면 전체 대사 합계는 null이다.
- 제외 공종은 별도 원가 필요 상태다. 근거 있는 해당 없음 선언은 표시하되 그 공종 금액을0원으로 만들지 않는다. 선언의 실제 타당성은 외부 검토 대상이다.
- 원문 행 참조를 NFKC·공백 정규화·소문자로 비교한다. 중복 그룹의 모든 행을 배분에서 제외하여 입력 순서로 유효 금액이 바뀌지 않는다. 원래 입력 부분합은 보존한다.

## 작업 흐름

견적 대사 화면의 행별 배분 입력은 미저장 초안이다. 연결 공종 갱신은 기존 일치 항목을 유지하고, 제거되는 입력은 확인 후 삭제한다. 금액·근거·범위 편집 시 이전 대사 결과는 무효화된다. 기존 잠금·세션 격리·저장본 충돌 보호를 유지한다.

명시적 대사 후 원장과 미확정 항목을 표시한다. 명시적 증빙 저장은 기존 Workspace 경로를 따르며 배분 원문도 JSON 가져오기·내보내기와 보고서에 보존한다. 8MiB/깊이8/노드12000/5초 가져오기 제한은 그대로다. 최대 문자열/이스케이프와 전체256배분 항목 회귀로 한도 안의 왕복을 확인한다. 전체 Workspace/봉인은 별도의 기존 바이트 상한을 유지한다.

통합검증2026.16의 `binding.construction-scope-ledger`는 배분 대사뿐 아니라 현재 계획 기준·원문/수량/부가세/검토 기준일 대사가 확인된 경우에만 내부 checked가 된다. 배분 변경은 SHA-256 검토 키를 변경한다. 이전 검토는 새 검토를 요구하며 과거 원본을 수정하지 않는다.

## 한계와 다음 단계

이 원장을 저장해도 사업비·수익·면적·주차를 자동 변경하지 않는다. 기존 주거 내부 수량의 명시적 포함액 교체 계약과는 별개다. 전체 견적의 명시적 사업비 채택은 기존 기본단가 포함액, 외장/세대 가산비, 부가세 기준, 누락·중복 공종을 함께 대사하는 별도 계약이 필요하며 아직 구현하지 않았다.

구조·기초·외벽·공용부·전체 MEP·소방 상세 물량의 자동 산출, 실제 견적 진위·현장 조건과 독립 QS 검산은 미완료다. `quantity-cost.developer`/`quantity-cost.finance-tax` 외부 검증 차단을 유지한다. 공식 경계·허가·전문가 승인도 미확정이다.
