# 전체 공사비와 견적의 입력 금액 비교

기준일: 2026-11-10, America/Chicago.
모델: `construction-quote-cost-comparison-2026.1`.

## 목적과 범위

기존 견적 대사의 `입력 행 합계 - BASE`는 기본 연면적 단가와의 비교다.
외장·추가 세대·상세 수량 증감이 포함된 현재 공사비와 같지 않으므로,
전체 견적 채택에 앞서 별도 읽기 전용 비교를 추가한다.

```text
현재 공사비 = 기본 공사비 + 외장 증감 + 추가 세대 가산 + 상세 수량 증감
견적 교체 비교 차액 = 대사된 견적 행 합계 - 현재 공사비
```

이 차액을 기존 공사비에 자동 적용하지 않는다. 견적 증빙 저장도 채택이
아니며, 면적·주차·사업비·수익·공식/전문가 승인 상태는 바뀌지 않는다.
미리보기의 `ready`는 입력 금액 비교 가능 상태이지 채택 또는 승인 가능
판정이 아니다.

## 검증 원칙

- 견적 원문·수량 대사와17공종 배분 원장 양쪽을 통과해야 전체 차액을
  표시한다. 미배분·누락·부가세 불일치·현재 계획과의 기준 불일치가 있으면
  차액은 미확정이다.
- 저장된 `economicsPreview` 숫자를 재사용하지 않고 현재 원본 입력에서
  계산한다. 재료·세대·상세 수량 비용도 현재 입력의 유효성을 확인한다.
- 미지원 추가 비용 필드를 버리고 통과시키지 않는다. 지원하는 재료·
  세대 비용 및 근거 메타데이터 범위를 확인하고 새 계산 계약은 별도로
  연결해야 한다.
- 명시된 정상 음수 증감은 차감액으로 보존한다. 미입력·비정상 수치를
  0원으로 대체하지 않으며, 계산 결과가 음수 또는 비유한이면 비교하지
  않는다. 상세 수량 계약이 없는 것과 존재하지만 불완전한 것은 구분한다.
- 기본 공사비에 남아 있는 공종은 가산비0원이라는 이유로 무료 또는
  제외 공종으로 바꾸지 않는다. 선택 재료의 단가 미입력은 미확정이다.
- 부가세는 입력자가 선언한 비교 기준이다. 실제 과세/면세 적용, 환급,
  가산비별 부가세와 견적의 실질적 포함 범위를 입증한 것이 아니다.

## 화면과 변경

견적 화면에서 명시적으로 `대사 실행`을 눌렀을 때만 비교한다. 기본·외장·
세대·수량·현재 합계·견적 합계·차액을 분리 표시한다. 현재 검토 후 견적,
재료, 세대 가산, 수량 계약이나 계획 기준이 바뀌면 기존 비교를 숨기고
다시 대사해야 한다. 입력 중 임의로 저장하거나 사업성을 계산하지 않는다.

## 남은 채택 계약

전체 견적을 실제 사업비에 적용하려면 다음 작업이 별도로 필요하다.

1. 견적에 포함된 공종과 철거·설계·예비비·금융 등 별도 비용의 경계를
   명시적으로 확인한다. 실제 물량·견적 원문 및 전문가 검산은 별도다.
2. 외장·세대·상세 수량을 포함한 전체 공사비를 한 번만 교체하는
   버전 결속 계약과 사용자 확인·해제 경로를 구현한다.
3. Stage2/3 및 월별 원장, 민감도·VE·스트레스, 변경 무효화, 잠금·복제,
   서버 봉인·보고서까지 같은 채택 금액을 다시 검증한다.

이 문서는 위 채택 계약이 구현됐다는 선언이 아니다. 이번 비교 추가는
재무 엔진과 저장 계약을 변경하지 않아 계산v227/통합검증2026.16을 유지한다.
