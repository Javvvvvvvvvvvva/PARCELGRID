# Hold Period Ledger 2026.3

## 목적과 범위

`hold-period-ledger-2026.3`은 개발단계 매각 수익과 보유할 임대자산을
분리한다. 전부 임대형뿐 아니라 주거·상가·업무 매각 풀이 섞인 혼합안도
계산하며, 임대차 만기 뒤 갱신과 신규 임차인 교체를 월별 기대값으로
반영한다.

기존 안정화 매각 손익·IRR·NPV와 공통 Pareto 순위는 바꾸지 않는다.
장기대출 조건은 `takeout-underwriting-2026.2`를 그대로 사용한다.

## 혼합 매각·임대 연결

혼합안은 먼저 개발 원장의 분양·매각 절차를 완료한 뒤 남은 임대자산을
보유하는 전략이다. 매각 풀의 현금흐름은 기존 개발 원장에 그대로 남기고,
종료월에 잡힌 임대자산 매각가만 제거한다.

```text
보유 전환 잔존 PF
= max(
    종료월 상환 전 PF
    - 종료월 진입 전 유보현금
    - 종료월 비임대 매각대금,
    0
  )

보유 전환월 자기자본 현금흐름
= 개발 원장 종료월 자기자본 현금흐름
- 임대자산 매각가
+ 장기대출 종결 순현금흐름
- 최초 임차인 공사비
- 최초 임대 중개수수료
```

따라서 분양·상가매각 대금이 PF를 이미 줄였다면 장기대출이 같은 원금을
다시 조달하지 않는다. 수수료와 최초 DSRA가 실행액을 넘으면 음수 종결
현금흐름도 추가 자기자본 유출로 유지한다.

현재 보유기간은 개발 매각 프로그램 종료 다음 달부터 시작한다. 임대가
더 일찍 안정화되더라도 개발 종료 전 중간 운영수입은 아직 넣지 않는
보수적 경계다.

## 최초 임대와 운영

```text
월 시장 예정임대료
= 안정화 연 잠재임대료 / 12
x 임대료 성장계수
x (1 - 구조적 공실률)

월 NOI = 유효총수입 - 월 운영비
정기상환 전 지분현금
= NOI
- 교체 준비금
- 임차인 공사비
- 임대 중개수수료
- 대수선
```

최초 무상임대는 보유 시작부터 입력 개월 동안 전체 예정임대료에서
차감한다. 최초 TI와 중개수수료는 보유 전환월에 한 번 반영한다.

## 임차인 갱신·교체 기대값

가중 평균 임대차 기간을 `T`개월, 갱신 확률을 `p`, 미갱신 확률을
`q = 1 - p`, 갱신 임대료 조정률을 `a`라 한다. 최초 계약은 보유 1개월차부터
`T`개월간 유지되고, 만기 이벤트는 `T+1`, `2T+1`개월차에 반복된다.

```text
갱신분 예정임대료 = 월 시장 예정임대료 x p x (1 + a)
교체분 예정임대료 = 월 시장 예정임대료 x q

유효총수입
= 갱신분 예정임대료
+ 교체분 예정임대료
- 갱신 무상임대
- 교체 유치 공실
- 교체 입주 후 무상임대
```

미갱신 면적의 비용은 각 만기 이벤트 월에 기대값으로 반영한다.

```text
교체 TI = 전체 임대면적 x q x 교체 TI 단가 / 10,000
교체 중개수수료
= 당시 월 시장 예정임대료 x 12 x q x 중개수수료율
```

갱신분은 임대료 조정과 갱신 무상임대를 적용하고, 현 버전에서는 별도
갱신 TI·중개수수료를 두지 않는다. 교체 유치 공실과 신규 무상임대의 합,
갱신 무상임대는 다음 만기와 겹치지 않아야 한다.

## 임차보증금

보증금은 반환 의무가 있는 제한계정이며 자기자본 수익률에 넣지 않는다.
만기 때 미갱신분 보증금과 갱신 임대료 조정분을 정산하고, 교체 공실 뒤
신규 임차가 시작되는 달에 신규 보증금을 다시 적립한다. 보유 종료에는
남은 제한 보증금을 전액 반환한다.

## DSRA와 장기대출

DSRA는 NOI가 정기 원리금보다 부족한 금액에만 사용한다. TI, 중개수수료,
대수선 또는 balloon 때문에 지분현금이 부족한 경우에는 사용하지 않는다.

```text
정기 원리금 부족 = max(정기 원리금 - max(NOI, 0), 0)
DSRA 사용 = min(DSRA 잔액, 정기 원리금 부족)
지분현금
= 정기상환 전 지분현금
- 정기 원리금
- balloon
+ DSRA 사용
- DSRA 보충
```

사용한 DSRA는 잉여 지분현금에서 목표액까지 보충한다. 대출이 상환되거나
보유가 끝나면 잔액을 회수한다. Balloon은 정기 DSCR에서 제외하고 발생월
자기자본 현금흐름에서 별도 상환한다. 보유 종료 전 만기가 오더라도 후속
재융자는 자동으로 만들지 않는다.

## Exit와 지표

Exit 가치는 일시적인 교체 공실·무상임대를 제거한 다음 12개월 안정화 NOI를
사용한다. 현재 임대차 사이클의 갱신 확률과 임대료 조정 기대값은 유지한다.

```text
최종 매각가 = max(Exit 안정화 연 NOI, 0) / Exit cap rate
매각 부대비 = 최종 매각가 x 매각 부대비율
```

결과는 개발+보유 세전 손익, NPV, IRR, Equity Multiple, 회수월, 최저 연
DSCR과 함께 다음을 반환한다.

- 개발단계 유지 매각대금과 보유 전환 임대자산 가치
- 임대차 만기 이벤트, 갱신·교체 비율과 발생월
- 교체 공실, 무상임대, 교체 TI와 중개수수료
- 최초·최대 보증금 제한계정
- 연차별 적용금리, 정기 원리금, 자본화 이자, DSRA와 balloon

## 근거 게이트

보유안은 기존 운용·Exit 입력에 가중 평균 임대차 기간을 추가로 요구한다.
보유기간 안에 만기가 있으면 갱신 확률을 요구하며, 확률이 0보다 크면 갱신
임대료 조정과 갱신 무상임대 근거를 요구한다. 확률이 100보다 작으면 신규
유치 공실, 신규 무상임대, 교체 TI와 중개수수료 근거를 요구한다. 현금흐름에
영향을 주지 않는 분기의 자료는 소스 게이트를 막지 않는다.

## 상태 계약

- `not-applicable`: 임대가치 또는 NOI가 없어 비적용
- `not-configured`: 보유기간 0년
- `terms-missing`: Exit cap, 임대차 기간 또는 장기대출 필수조건 누락
- `terms-invalid`: 기간 조합이나 입력 범위 오류
- `modeled-unverified`: 계산 가능하지만 장기대출 확약 미확인
- `refinance-shortfall`: 종결 현금흐름으로 잔존 PF 상환 부족
- `commitment-feasible`: 확인 확약액 기준 잔존 PF 상환 가능

## 미산정 경계

- 개발 종료 전 임대 안정화 구간의 운영수입
- 임차인·호실별 서로 다른 만기와 단계적 만기분산
- 중도해지, 연체, 대손, 보증금 미회수와 원상복구 분쟁
- 갱신 TI·갱신 중개수수료와 업종별 별도 조건
- 수익 풀별 서로 다른 임대차 기간·갱신률·임대료 경로
- 재산세, 반복 보험료, 제한계정 운용수익과 후속 재융자

따라서 갱신률을 확정 미래현금으로 해석하지 않는다. 임대차 현황표가 있는
실제 자산은 후속 lease-by-lease 원장으로 교체해야 한다.

## 회귀 기준

- 혼합안의 매각대금은 개발 원장에 남고 임대자산 가치만 보유로 전환된다.
- 비임대 매각대금과 유보현금이 잔존 PF를 먼저 줄인다.
- 임대차 만기 이벤트 수와 발생월은 `T`개월 주기와 일치한다.
- 갱신·교체 기대비율 합은 100%이며 각 손실과 비용이 독립 항목으로 남는다.
- 교체 보증금은 기존 보증금 반환 뒤 신규 임차 시작월에 다시 적립된다.
- DSRA는 NOI의 정기 원리금 부족에만 사용하고 TI·balloon에는 사용하지 않는다.
- 입력 객체와 개발 현금흐름 배열은 변경하지 않는다.
