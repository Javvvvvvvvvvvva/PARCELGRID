# ParcelGrid 2026-08-23 Launch Readiness

## 목표

2026년 8월 23일 한국 현장 홍보 시작 전까지 주소 입력부터 검증 보고서까지 하나의 사용자 여정으로 동작하는 출시 후보를 완성한다.

## 출시 기준

- 주소 입력 → 현황 분석 → 계획 스튜디오 → 사업성 검토 → 전문가 협업 → 검증 보고서가 끊기지 않는다.
- 공식 데이터·사용자 입력·알고리즘 추천을 서로 구분해 표시한다.
- 미확정 규제와 가정값을 법적 확정값처럼 자동 차단에 사용하지 않는다.
- 초보자 빠른 계획과 전문가 정밀 편집이 같은 계획 데이터를 공유한다.
- 공사비와 손익은 Low / Base / High 범위로 확인할 수 있다.
- 보고서에는 입력값, 계산 근거, 데이터 출처, 검토 필요 항목이 남는다.

- [x] 계획안 확정 → 동일 ID 사업성 시나리오 생성·전달 검증

- [x] Low(-15%) / Base / High(+20%) 공사비와 손익 범위 계산·표시 검증
- [ ] 도로 이격 → 주차 배치 → 필요 시 필로티 → 층별 세대 순서 검증
