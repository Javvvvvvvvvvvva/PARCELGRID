# PARCELGRID 세후 원장 계약 2026.2

> 이 문서는 보존용이다. 현재 계약은 `AFTER-TAX-LEDGER-2026.3.md`를 따른다.

기준일: 2026-09-09  
원장 모델: `after-tax-ledger-2026.1`  
입력 계약: `expert-tax-input-2026.2`

## 변경점

세후 계산식과 8개 세목 계약은 2026.1과 같다. `expert-confirmed` 상태에는 입력
문자열만으로 만든 작성자 정보가 아니라 현재 로그인 사용자의 인증된 확인 정보가
추가로 필요하다.

확인 정보는 사용자 ID, 이메일, 이름, 조직, `accountant` 또는 `tax-advisor`
전문가 역할과 서버에 제출한 확인 시각을 가진다. 계약의 작성자 이름은 인증 주체와
일치해야 한다. 일반 사용자, 분석가 자격만 있는 사용자, 다른 이름을 적은 계약은
모든 세목이 채워져도 의사결정 등급이 아니다.

## 계산 원칙

세전 원장에 이미 포함된 기존 부동산 취득세는 전문가 금액과 1만원 이내로 대사만
하고 다시 차감하지 않는다. 나머지 세목의 확정 납부·환급 현금흐름만 월별 세전
자기자본 현금흐름에 더해 세후 손익, NPV, IRR, Equity Multiple과 회수기간을
다시 계산한다.

`draft`는 비교 가능한 초안일 뿐 확정 순위에 사용할 수 없다. `expert-confirmed`는
전 세목 판정, 납세의무자, 기준일, 문서 번호, 프로젝트 전용 원문 경로, 유효한
SHA-256과 인증된 전문가 확인 정보가 모두 유효할 때만 성립한다.

이 확인은 세무 신고나 법적 전자서명을 대신하지 않는다. 실제 과세표준, 중과·감면,
부가가치세 과세 여부와 사업주체별 세무 처리는 담당 전문가가 원문과 최신 법령으로
다시 확인한다.
