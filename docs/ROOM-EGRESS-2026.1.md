# 상세 실·피난·층간 코어 예비 검증

기록일: 2026-10-22, America/Chicago. 기존 디자인을 유지한 기능 고도화 4차.

## 판정 경계

이 기능은 저장된 가정 도면의 구획·개구부·연결 그래프와 계단 예약공간을 검사한다. 공식 지적 경계, 법정 피난 적합성, 인허가, 전문가 승인을 확정하지 않는다. 모든 결과의 `approvalStatus`는 `unverified`이며 대표안 확정 검사에서 `pass`로 승격하지 않는다.

- 실 구획: `missing`, `conflict`, `preliminary-fit`.
- 피난·코어: `missing`, `conflict`, `preliminary-chain`.
- 후보 없음은 해당 직사각형 템플릿/계단 형식의 한계다. 해당 부지에 건축이 불가능하다는 의미가 아니다.
- 형상이 있는 참고/가정 경계는 그 좌표 안에서만 검사한다. 공식 자료의 신뢰도는 별도 근거 체계에서 유지한다. 좌표가 없으면 생성과 연결 판정을 보류한다.

## 저장 계약

- `FloorProgram.interiorLayout.roomLayouts[]`: 세대 ID, 부모 세대/현관 기준, 생성 가정, 선택 현관, 방·거실·주방·욕실·통로, 실 출입문.
- `PlanningScenario.egressPlan`: 계단/개구부 가정과 명시적으로 연결한 지상 출구.
- 부모 세대 외곽·벽 두께·현관 변경은 상세 실을 stale로 만든다. 층 면적 프로그램·외곽 변경도 상위 검사에서 차단한다.
- 지상 구획/문 변경은 출구 재연결을 요구한다. 객체 키 순서만 달라지는 canonical Workspace 저장은 stale로 처리하지 않는다.
- Zod 저장 경계가 중첩 형식·숫자·배열 크기를 검사한다. 이전 실내 구획에는 상세 실을 선택 필드로 유지한다.
- 계획안 복제 시 층/세대 ID가 달라지므로 실내 구획과 출구 참조를 초기화한다. 잠긴 계획안은 UI와 데이터 계층 모두에서 변경을 차단한다.

## 상세 실

상위 실내 구획 예비 검사 후 유효 현관 방향에 맞춰 T자 통로 템플릿을 탐색한다. 전면에는 욕실·현관 통로·주방, 후면에는 침실과 거실을 둔다. 침실 0은 거실·취침 통합이다. 후보를 저장한 뒤 실 위치·치수·회전 및 문 위치·유효폭을 편집할 수 있다.

내부 기본 가정이며 **법정 최소치가 아니다**:

| 항목 | 기본 가정 |
| --- | --- |
| 침실 | 1개, 선택 범위 0~3개 |
| 실내 벽 두께 | 0.12 m |
| 내부 통로 유효폭 | 0.90 m |
| 실 출입문 유효폭 | 0.80 m |
| 주방·욕실 구획 깊이 | 1.60 m |
| 침실 / 거실 최소 유효면적 | 6 / 7 ㎡ |
| 주방 / 욕실 최소 유효면적 | 4 / 3 ㎡ |
| 침실·거실 / 주방·욕실 최소 유효폭 | 2.0 / 1.2 m |

면적은 직사각형 공간의 폭·깊이에서 가정 벽 두께를 뺀 값의 곱이다. 법정 전용면적 산정이 아니다. 세대 외곽 포함, 구획 겹침, 실 구성 수, 최소 폭/면적, 공유 벽 개구부, 독립 현관 경로를 검사한다. 다른 침실·거실·주방·욕실을 통과하는 접근은 인정하지 않는다.

표시 길이는 한 유효 모서리→실 중심→문 중심→통로→현관의 중심선 후보이다. 최단경로, 최장 피난거리, 가구를 회피한 경로, 사람 폭을 가진 이동 궤적을 계산한 값이 아니다.

## 피난·층간 코어

1. 각 층의 저장된 실내 구획이 현재 외곽·프로그램에 맞는지 검사한다.
2. 인접 층만 연결한다. B1→1층은 인접하며, 중간층 누락이나 잘못된 높이는 연결을 만들지 않는다.
3. 현재 층 바닥 높이 차와 설정 단높이로 짝수 단 수를 계산한다.
4. 두 계단 구간과 앞뒤 계단참을 포함한 사각 예약공간이 위·아래 코어의 유효 영역에 같은 XY 위치로 들어가는지 검사한다.
5. 지상 공용부 외벽의 선택 개구부와 코어를 연결하고, 외부 여유 공간이 입력 대지 안에 있는지 검사한다.
6. 각 실→현관→공용부→코어 연결과 층간 연결 그래프를 지상 출구까지 합성한다.

기본 가정: 계단 유효폭 1 m, 단너비 0.26 m, 최대 단높이 0.18 m, 계단참 깊이 1.2 m, 두 계단 간격 0.2 m, 계단실 벽 두께 0.15 m, 경로 문 유효폭 0.8 m. 모두 내부 설계 가정이며 법규 판정 값이 아니다.

`N = 2 × ceil(층고 / 최대단높이 / 2)`, 단높이 = 층고 / N.

`예약 폭 = 2 × 계단유효폭 + 간격 + 2 × 계단실벽두께`

`예약 깊이 = (N / 2 - 1) × 단너비 + 2 × 계단참깊이 + 2 × 계단실벽두께`

층고 3 m의 기본 예약공간은 18단, 단높이 약 167 mm, 2.50 × 4.78 m다. 실제 계단 단면/시공 도면이 아니며, 한 코어에 계단과 승강기가 함께 들어간다는 의미도 아니다.

지상 필로티/주차층도 공용부 구획을 저장할 수 있다. 코어·복도 총면적이 입력 공용면적을 초과하면 충돌이다. 필요한 공용면적을 주차·주거면적에서 자동 차감하지 않는다.

피난 탭은 현재 주차 Snapshot의 주차면·가정 기둥과 지상 공용부/출구 여유 공간의 간섭도 검사한다. 일반 공간 체크의 코어 검사에는 주차 Snapshot이 없으므로 별도 미검증 범위를 표시한다. 어느 쪽도 대표 승인 가능 상태가 되지 않는다.

## 남은 전문 검토

법정 직통계단 개수, 피난/특별피난계단 해당 여부, 용도·규모별 보행거리, 방화구획·문 성능, 문짝 회전, 계단참의 실제 출입 접속, 연속 계단 상세, 머리높이·난간·구조, 승강기, 장애인 접근, 외부 안전 통로의 도로 연결은 미검증이다. 상세 실의 창호·채광·환기·급배수·방수·가구 배치도 미검증이다.

범위 구분을 위한 공식 해석례 참고: [직통계단 관련 해석례](https://law.go.kr/LSW/expcInfoP.do?expcSeq=335575), [계단참 관련 해석례](https://law.go.kr/expcInfoP.do?expcSeq=339033). 해석례는 현행 전체 규정의 대체물이 아니며 해당 문서의 수치를 이번 엔진의 법정 기준으로 채택하지 않았다.
