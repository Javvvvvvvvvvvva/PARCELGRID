# Hold Period Ledger 2026.2

> 역사 버전이다. 현행 계약은 `HOLD-PERIOD-LEDGER-2026.3.md`를 따른다.

## 목적과 범위

`hold-period-ledger-2026.2`는 전부 임대형 개발안의 안정화 매각 회수액을
장기대출 종결 현금흐름으로 교체하고, 운영과 최종 매각까지 월별 자기자본
현금흐름을 연결한다. 기존 안정화 매각 손익·IRR·NPV와 공통 Pareto 순위는
바꾸지 않는다.

이 버전은 `takeout-underwriting-2026.2`의 납부유예, 이자만 납부,
변동금리 예상 경로, 자본화 이자, balloon과 DSRA를 실제 보유 원장에 반영한다.
매각 수익 풀이 섞인 안은 아직 `not-applicable`이다.

## 재융자월 연결

```text
재융자월 자기자본 현금흐름
= 개발 원장 종료월 자기자본 현금흐름
- 안정화 임대 자산가치
+ 장기대출 종결 순현금흐름
- 최초 임차인 공사비
- 최초 임대 중개수수료
```

장기대출 종결 순현금흐름은 실행액에서 수수료와 최초 DSRA를 차감한 값이며
음수일 수 있다. 최초 DSRA 적립은 원장 행에 감사용으로 기록하지만 위
종결 순현금흐름에 이미 차감되었으므로 다시 차감하지 않는다.

## 운영 현금흐름

```text
월 예정 임대료 = 월 잠재 임대료 x (1 - 공실률)
월 유효총수입 = 월 예정 임대료 - 초기 무상임대
월 NOI = 월 유효총수입 - 월 운영비
정기상환 전 현금 = NOI - 교체 준비금 - 대수선
```

장기대출 상환표의 월별 적용금리, 발생이자, 현금 지급이자, 자본화 이자,
예정원금, 정기 원리금, balloon과 잔액을 같은 보유월에 연결한다.

## DSRA 제한현금

최초 DSRA 목표액은 장기대출 모델의
`최대 연 정기상환액 / 12 x DSRA 개월 수`다.

```text
정기 원리금 부족 = max(정기 원리금 - max(정기상환 전 현금, 0), 0)
DSRA 사용 = min(DSRA 잔액, 정기 원리금 부족)
사용 후 지분현금 = 정기상환 전 현금 - 정기 원리금 - balloon + DSRA 사용
DSRA 보충 = min(max(사용 후 지분현금, 0), 목표액 - DSRA 잔액)
최종 지분현금 = 사용 후 지분현금 - DSRA 보충
```

DSRA는 정기 원리금 부족에만 사용한다. 운영비, 대수선, balloon, PF 상환,
투자자 배당에는 사용하지 않는다. 대출이 전액 상환되거나 보유가 끝나면
잔액을 자기자본에 회수한다. 연차표의 `DSRA 순적립`은 적립을 양수,
사용과 회수를 음수로 표시한다.

## Balloon과 종료 매각

계약 만기 월에는 정기상환 뒤 잔존 대출을 balloon으로 자기자본에서 별도
상환한다. 보유 종료보다 만기가 빠르면 후속 재융자를 만들지 않고 해당 월에
전액 상환한다. 이때 남은 DSRA도 회수한다.

```text
종료 연 NOI
= 종료시점 성장 임대료 x (1 - 공실률)
- 종료시점 성장 운영비

최종 매각가 = max(종료 연 NOI, 0) / Exit cap rate
매각 부대비 = 최종 매각가 x 매각 부대비율

종료월 지분현금
= 운영 지분현금
+ 최종 매각가
- 매각 부대비
- 당시 잔존 장기대출 원금
+ 해제되는 DSRA
```

Balloon이 먼저 발생해 대출잔액이 0이면 종료월 잔존대출 상환은 0이다.

## 보증금과 수익지표

임차보증금은 반환 의무가 있는 별도 제한계정이다. 유입, 잔액, 종료 환급을
기록하지만 PF 상환, 운영비, 원리금, 배당과 IRR·NPV·Equity Multiple에는
사용하지 않는다.

연 DSCR은 해당 연차 NOI를 같은 연차 `정기 원리금`으로 나눈다. 자본화
이자와 balloon은 분모에서 제외하고 각각 별도 열과 합계로 공개한다. 결과는
개발+보유 세전 손익, NPV, IRR, Equity Multiple, 회수월, 최저 연 DSCR,
최초·누적 DSRA, 자본화 이자, 예정원금, balloon과 종료 잔존대출을 반환한다.

## 상태 계약

- `not-applicable`: 임대가치·NOI가 없거나 매각 풀이 섞인 안
- `not-configured`: 보유기간 0년
- `terms-missing`: Exit cap 또는 장기대출 필수조건 누락
- `terms-invalid`: 보유 또는 장기대출 조건 오류
- `modeled-unverified`: 계산 가능하지만 장기대출 확약 미확인
- `refinance-shortfall`: 수수료·DSRA 포함 종결 현금흐름으로 PF 상환 부족
- `commitment-feasible`: 확인 확약액 기준 PF 상환 가능

## 미산정 경계

- 혼합 매각·임대형의 매각대금, 잔존 임대자산과 대출 배분
- 임차인별 임대차 만기, 교체·갱신, 후속 공실·무상임대·TI·중개수수료
- 임대료 연체, 대손, 재산세와 반복 보험료
- 만기 후 후속 재융자, covenant cure와 default
- 제한계정 운용수익

전문가 세금 일정은 별도 `after-tax-ledger-2026.1`에 연결되며, 위 세전
원장 자체가 법인세·소득세·부가세를 자동 추정하지 않는다.

## 회귀 기준

- 납부유예 이자는 원금에 가산되고 현금 상환에는 포함되지 않는다.
- 이자만 납부 구간은 원금이 줄지 않는다.
- 적용금리는 리셋 주기와 floor/cap 범위를 벗어나지 않는다.
- 예정원금, balloon과 종료 잔존대출 합계는 실행원금과 자본화 이자 합계와
  대사된다.
- 최초 DSRA는 종결 현금흐름에서 한 번만 차감된다.
- DSRA는 정기 원리금 부족에만 사용되고 잉여현금에서 목표액까지 보충된다.
- 수수료와 DSRA가 실행액을 넘는 음수 종결 현금흐름도 자기자본 유출로 남는다.
- 입력 객체와 개발 현금흐름 배열은 변경하지 않는다.
