# Release Smoke Test

Use `서울 도봉구 쌍문동 281-23` as the primary end-to-end demo parcel.

1. Create a project from the address and enter a total acquisition price.
2. Confirm official facts, user inputs, and algorithm recommendations are visually distinct.
3. Open Plan Studio and edit one value in Quick Plan.
4. Switch to Expert Edit and confirm the same value is retained.
5. Confirm reference-only constraints remain review items and do not hard-block edits.
6. Select the representative plan and continue to feasibility review.
7. Confirm construction cost and profit show Low / Base / High ranges.
8. Confirm total cost plus profit reconciles to revenue.
9. Confirm equity plus PF loan reconciles to the financed project cost basis.
10. Continue through expert handoff and generate the final verification report.
11. Export the report and confirm its sources, assumptions, warnings, 3D view, and financial basis are readable.
