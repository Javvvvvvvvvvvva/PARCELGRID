# PARCELGRID 제품 확장 원칙: 재료비·3D 재질·AI 콘셉트 이미지

> 2026-08-26 상태: 아래 원칙 중 총 취득대금 직접 입력, 재료 선택과 3D 미리보기, 출처 있는 외장비 조정, Geometry 잠금형 AI 콘셉트 렌더, 보고서 provenance는 구현됐습니다. 구조·지붕·창호·내부 마감까지의 상세 물량산출과 재료·노무·장비·간접비 분리는 아직 후속 범위입니다.

## 1. 현재 단계의 역할

### 새 부지 등록

- 주소와 사용자가 알고 있는 **부동산 총 취득대금**을 직접 입력한다.
- 총 취득대금은 토지와 기존 건물을 함께 취득하는 전체 대금이다.
- 주변 실거래·공시지가·알고리즘 값은 입력값을 대신 채우지 않는다.
- 시장 데이터는 사용자가 입력한 금액의 위치를 이해하기 위한 참고자료로만 표시한다.

### Stage 1 현황 분석

- 현재 토지, 기존 건물, 법규, 도로, 주변 시장을 읽기 전용으로 설명한다.
- 사실 데이터, 파생 분석, 미확인 항목을 구분한다.
- 계약서·감정평가서 업로드와 가격 확정은 Stage 3 가격 검증 및 전문가 인계에서 처리한다.
- 미래 건물의 형태, 재료, 공사비는 Stage 2 이후에 다룬다.

## 2. 재료 기반 공사비

재료 선택은 단순한 색상 옵션이 아니라 동일한 계획 매스에서 공사비와 시각화를 함께 바꾸는 입력값이어야 한다.

재료 카탈로그의 최소 필드:

- 고유 ID와 표시 이름
- 적용 부위: 구조, 외벽, 지붕, 창호, 내부 마감
- 단가와 단위: 원/㎡, 원/m, 원/개 등
- 단가 기준일과 출처
- 손실률, 시공 난이도, 지역 보정
- 3D 미리보기용 색상·텍스처
- AI 이미지 생성용 재료 설명 키워드

계산 순서:

1. 검증된 계획 매스에서 구조·외벽·지붕·창호 면적을 산출한다.
2. 사용자가 부위별 재료를 선택한다.
3. 수량 × 단가 × 손실률 × 지역·난이도 보정을 계산한다.
4. 재료비, 노무비, 장비비, 간접비를 분리한다.
5. Stage 3 총공사비, PF, IRR, NPV와 보고서에 같은 결과를 전달한다.

면적을 알 수 없는 경우 임의 수량으로 확정 계산하지 않고 **미산정** 또는 **개략 범위**로 표시한다.

## 3. 3D 재질 미리보기

- 현재 파란 계획 매스의 형상과 위치는 그대로 유지한다.
- 선택한 외벽·지붕·창호 재료를 렌더링 레이어에서만 적용한다.
- 법규 검증용 형상과 시각화용 재질을 분리해 재질 변경이 배치·면적·법규 결과를 바꾸지 않게 한다.
- 텍스처는 실제 시공 상세가 아닌 개념 미리보기임을 표시한다.

## 4. AI 콘셉트 이미지

AI 이미지는 계획을 새로 결정하는 기능이 아니라 검증된 매스와 선택 재료를 시각적으로 설명하는 기능이다.

생성 입력 JSON의 최소 구조:

```json
{
  "projectId": "string",
  "geometryHash": "string",
  "camera": {
    "view": "street | aerial | courtyard",
    "azimuth": 0,
    "elevation": 0
  },
  "massing": {
    "floors": 0,
    "heightM": 0,
    "footprint": "validated geometry reference"
  },
  "materials": [
    {
      "part": "facade",
      "materialId": "brick-red-01",
      "description": "red clay brick"
    }
  ],
  "context": {
    "address": "string",
    "surroundingBuildingScale": "string",
    "roadCondition": "string"
  },
  "style": {
    "purpose": "concept report",
    "weather": "clear",
    "realism": "architectural visualization"
  }
}
```

생성 결과에는 다음 provenance를 저장한다.

- 모델과 버전
- 생성 시각
- geometry hash
- 재료 선택 버전
- 최종 프롬프트와 JSON
- 사용자 선택 이미지
- “AI 콘셉트 이미지 · 인허가/시공도면 아님” 표시

## 5. 보고서 연결

보고서에는 같은 계획안 기준으로 다음을 함께 보여준다.

- 검증된 매스와 주요 면적
- 선택 재료와 출처 있는 단가
- 재료별·공종별 공사비
- AI 콘셉트 이미지
- 사용한 JSON·프롬프트와 생성 이력
- 미확인 가정과 전문가 확인 항목

## 6. 구현 순서

1. Stage 1 일반 사용자 흐름과 총 취득대금 직접 입력
2. Stage 3 가격 증빙·전문가 검증
3. Stage 2 재료 카탈로그와 부위별 선택
4. 매스 기반 수량 산출 및 재료별 공사비
5. 3D 재질 미리보기
6. JSON·프롬프트 생성
7. AI 이미지 API 연결
8. 보고서 provenance와 함께 출력
